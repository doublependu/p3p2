A shared world: the yard

Starting…

This page stands in for a game whose world outlives everybody in it. The world is raised from a seed that the first player to host offers the room. Every stone taken and every wall built is an op in the room's log, so the first to reach a stone has it on every screen, and the host packs the world into snapshots that fit the server. Where you stood is a value of your own that the room keeps. The dark tile is a door to the cellar, another page of the same game in the same room. T opens the chat, since Enter builds.
