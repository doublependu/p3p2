Turns example

Playing alone. Open the 👥 panel in the corner and paste a room URL to host.

This page stands in for a game played in turns: noughts and crosses. Everything is in the room's log: taking a seat, every move, the next game. Each page builds the board from the same ops in the same order, and ignores an op that breaks the rules, so every page has the same board without a host. A move is shown when its op comes back, as on every other page. The room keeps the log: close the page, and the game is there tomorrow.
