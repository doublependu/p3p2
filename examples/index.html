p3p2 examples

  • Chat: the built-in panel, plus the same room used through the API
  • Ball and bricks: one player's browser runs the game for everyone, the room's log keeps the wall, and the next player takes over when the host goes
  • Cards: the host deals each player a card in one message, and nobody sees another's until it is shown
  • Turns: noughts and crosses, kept entirely in the room's log: seats, moves, the next game, and a game that waits while a player is away
  • A shared world: a world raised from a seed the room keeps, stones and walls through the log, snapshots packed to fit the server, where each player stood, and a second page in the same room
  • Arena: one page runs the bots and a ball, and tells each player only what it can see; the others' figures drawn smoothly; the round outlives its host
  • Duel: hidden boards and probes in turns, with a promise in the log about what each player hid; one page, one script tag, no bundler
  • Rally: one ball on the room's clock, decided by the page it is heading to, and a menu of the game's own in place of the panel

World, arena and rally are Vite projects: npm run examples builds them with this checkout's client before it serves this page. The duel takes the released client from jsDelivr.
