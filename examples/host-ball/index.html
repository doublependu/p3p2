Ball and bricks

Playing alone. Open the 👥 panel in the corner and paste a room URL to host.

This page stands in for a game that needs one player to be in charge. The host's browser moves the ball and decides which brick it hits; the others see what the host sends them, and a click anywhere asks the host to send the ball that way. Every brick that falls is an op in the room's log, which the server numbers and saves. Close the host's tab and the next player carries on with the same ball. Let everyone leave, and the wall is as you left it when somebody comes back.
